Definition: An AI agent is an intelligent system that takes a high level goal from a user and autonomously plans, decides, and executes a sequence of actions using external tools

-Agents combine LLMs (acting as the reasoning engine) with Tools (APIs or search functions) to perform actions
Agents are goal driven, capable of planning/breaking down tasks, aware of their available tools, maintain context (memory), and are adaptive to new information

ReAct (Reasoning + Acting) pattern is one of the design pattern which allows the model to interleave internal thought processes with external tool usage menaing instead of  generating answer in one go it does so step by step through thought tracese.
