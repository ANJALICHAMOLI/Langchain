What is RAG?: RAG is defined as a technique that retrieves external knowledge (e.g., company databases, PDFs) to provide context to an LLM. 

or

rag is a technique that combines information retrival with language generation where a model retertives documents form a knowledge base provided and then uses them as context to generate accurate and grounded responses 

benifits:-
1: Use of up to date information:Access to up to date Information Unlike standard models limited by their training data eg gpt, RAG allows the system to retrieve current, real time information to provide accurate responses.

2.Improved data privacy: You can process sensitive or personal documents locally without needing to upload them to a public service and hence making them relaible and a good choice over such tasks

3.No document size limits: While standard LLMs have a fixed context length, RAG handles large documents by splitting them into smaller chunks, making it possible to query massive datasets that would otherwise be too large to process at once

4.Increased accuracy: By providing the model with specific, grounded context from your own sources, you reduce the likelihood of the model hallucinating or providing outdated answers



Core RAG Components :

The four fundamental pillars of any RAG architecture: Document Loaders, Text Splitters, Vector Databases, and Retrievers.


1- DOCUMENT LOADRER-
document loaders are utility components designed to ingest data from diverse sources and convert them into a standardized format known as Document Objects . This process is a crucial first step in building RAG (Retrieval-Augmented Generation) applications, as it prepares raw data for subsequent tasks like chunking, embedding, and retrieval .

Core Characteristics:

Standardized Output: Every loader, regardless of the source (PDF, text, web, etc.), outputs a list of Document objects .
Structure: Each document consists of two primary components: page_content (the actual data) and metadata (contextual info like source, page numbers, or timestamps).
Commonly Used Loaders:

        TextLoader
        PyPDFLoader
        DirectoryLoader
        CSVLoader
functions->
.load(): Performs eager loading, pulling the entire dataset into memory at once. Best for smaller files .
.lazy_load(): Provides a generator that fetches documents one at a time on demand. This is highly recommended for large-scale data to minimize memory usage and stream processing
